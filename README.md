# CodeXperience 🌾

**CodeXperience** es una experiencia educativa inmersiva (Agritech) diseñada para aprender programación mediante la exploración, retos y la resolución de problemas. Adéntrate en una colonia agrícola futurista donde los sistemas automatizados han fallado, y usa tu código para reparar los robots y restaurar el funcionamiento del ecosistema.

## 🌟 Características Principales

* **Explora:** Recorre diferentes zonas de la colonia, descubre estaciones, robots y problemas que necesitan una solución.
* **Programa:** Escribe instrucciones lógicas y secuencias para controlar máquinas y automatizar tareas.
* **Resuelve:** Cada desafío plantea un problema diferente; el éxito dependerá de tu ingenio y de cómo estructures tu código.
* **IA Adaptativa:** El sistema aprende cómo aprendes, ajustando la dificultad de los desafíos según tus aciertos y errores.
